# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

We prioritize the security of dock-radar and its users. If you discover a security vulnerability, please report it privately:

1. **Email Disclosure**: Send details to the maintainer via GitHub contact or security advisory.
2. **Details to Include**:
   - Description of the issue and potential impact.
   - Minimal reproducible steps or proof-of-concept code.
   - Suggested mitigation steps if available.

We kindly request that you give maintainers reasonable time to investigate and address the vulnerability before public disclosure.
