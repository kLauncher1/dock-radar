# 📡 Dock-Radar

**अल्ट्रा-लाइटवेट सिंगल बाइनरी कंटेनर और सिस्टम मेट्रिक्स मॉनिटर (एम्बेडेड डार्क-मोड वेब डैशबोर्ड के साथ)**

<sub>kLauncher1 द्वारा निर्मित · होमलैब और एज नोड्स के लिए न्यूनतम संसाधन डिज़ाइन</sub>

---

## ⚡ मुख्य विशेषताएं

- **सिंगल बाइनरी परिनियोजन**: Go के `//go:embed` के माध्यम से वेब डैशबोर्ड सीधे बाइनरी में एम्बेड किया गया है। Node.js या बाहरी वेब सर्वर की आवश्यकता नहीं है।
- **अल्ट्रा-लो मेमोरी उपयोग**: लगातार **15 MB से कम RAM** में चलता है, जो कम-स्पेक VPS और रास्पबेरी पाई के लिए आदर्श है।
- **डायरेक्ट डॉकर सॉकेट निरीक्षण**: `/var/run/docker.sock` या विंडोज़ नेम्ड पाइप्स के साथ सीधे संचार करता है।
- **होस्ट सिस्टम टेलीमेट्री**: रीयल-टाइम CPU कोर, गोरूटीन्स, आवंटित RAM, GC चक्र और अपटाइम को ट्रैक करता है।
- **डार्क-मोड ग्लास मॉर्फिज्म UI**: लाइव कंटेनर निरीक्षण और इवेंट लॉग के साथ उच्च-कंट्रास्ट डैशबोर्ड।

## 🚀 त्वरित शुरुआत

```bash
git clone https://github.com/kLauncher1/dock-radar.git
cd dock-radar

# सीधा निष्पादन
go run .

# सिंगल बाइनरी संकलन
go build -ldflags="-s -w" -o dock-radar .
./dock-radar
```

वेब डैशबोर्ड: 👉 **`http://localhost:9080`**
