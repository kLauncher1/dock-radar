## ⚡ प्रमुख विशेषताएँ (Highlights)

- **एकल निष्पादन योग्य बाइनरी परिनियोजन (Single Executable Deployment)**: वेब डैशबोर्ड Go के `//go:embed` निर्देश के माध्यम से सीधे Go बाइनरी में एम्बेडेड है। किसी Node.js रनटाइम, बाहरी संपत्तियों या अलग फ्रंटएंड सर्वर की कोई आवश्यकता नहीं है।
- **अल्ट्रा-लो मेमोरी पदचिह्न (Ultra-Low Memory Footprint)**: सीमित वृत्ताकार रिंग बफ़र्स (Circular Ring Buffers) के साथ लगातार **15 MB रैम से कम** में चलता है, जो इसे कम-विशिष्टता वाले VPS, Raspberry Pi और होमलैब वातावरण के लिए आदर्श बनाता है।
- **अनुकूली कर्नेल eBPF टेलीमेट्री और व्यवहार सुरक्षा इंजन**: शुद्ध मानक-पुस्तकालय सॉकेट फ्लो ट्रैकर और Linux `/proc/net/tcp` निरीक्षक जो वास्तविक समय में TCP/UDP सॉकेट कनेक्शन, बाइट थ्रूपुट और राउंड-ट्रिप लेटेंसी (RTT) को मापता है। अंतर्निहित व्यवहार सुरक्षा इंजन अप्रत्याशित शेल निष्पादन (`execve`), विशेषाधिकार वृद्धि (`setuid`), मेमोरी निरीक्षण (`ptrace`), संवेदनशील होस्ट क्रेडेंशियल्स एक्सेस (`/etc/shadow`), डॉकर सॉकेट दुरुपयोग और आउटबाउंड माइनिंग कनेक्शन के लिए स्वचालित पहचान नियमों के साथ कंटेनर सिस्टम कॉल की निगरानी करता है।
- **वितरित अल्पकालिक लॉग स्टोरेज और S3 ऑफलोडर**: इन-मेमोरी कंटेनर लॉग्स को क्रिप्टोग्राफ़िक SHA-256 अखंडता चेकसम और परमाणु डिस्क लेखन के साथ gzip (`.gz`) चंक्स में संपीड़ित करता है। बैकग्राउंड एसिंक्रोनस ऑफलोडर शुद्ध मानक लाइब्रेरी AWS SigV4 साइनर का उपयोग करके S3-संगत क्लाउड ऑब्जेक्ट स्टोरेज (AWS S3, MinIO, Cloudflare R2) में चंक अभिलेखागार को स्ट्रीम करता है।
- **ज़ीरो-डाउनटाइम रोलिंग रीस्टार्ट और ट्रैफ़िक ड्रेनिंग (Zero-Downtime Rolling Restarts)**: प्रतिकृतियों, कंपोज़ स्टैक, या लेबल समूहों में क्रमिक अनुक्रमिक कंटेनर रीस्टार्ट को व्यवस्थित करता है। कॉन्फ़िगर करने योग्य टाइमआउट और रिवर्स प्रॉक्सी वेबहुक अधिसूचना के साथ इन-फ्लाइट ट्रैफ़िक ड्रेनिंग, बहु-चरणीय तत्परता जांच (डॉकर स्थिति, हेल्थचेक, HTTP `/healthz` एंडपॉइंट्स) और डाउनटाइम को रोकने वाले स्वचालित रोलबैक ट्रिगर्स शामिल हैं।
- **डायनामिक मल्टी-नोड क्लस्टर मेश और गॉसिप डिस्कवरी**: शून्य-कॉन्फ़िगरेशन LAN UDP प्रसारण ऑटो-डिस्कवरी (पोर्ट 9085) एक हल्के SWIM-आधारित गॉसिप प्रोटोकॉल के साथ जुड़ा हुआ है। इसमें प्रत्यक्ष यादृच्छिक पिंग/पावती, अप्रत्यक्ष सहायक पिंग ($k=3$), संदेह टाइमर, और वेब डैशबोर्ड में विकेंद्रीकृत क्लस्टर स्वास्थ्य आम सहमति शामिल है।
- **पूर्वानुमानित विसंगति का पता लगाना और OOM थकावट रडार**: मेमोरी संतृप्ति ढलान ($m$), अवरोधन ($c$), और गतिशील समय-से-थकावट (TTE, Time-to-Exhaustion) का पूर्वानुमान लगाने वाला वास्तविक समय OLS रैखिक प्रतिगमन विश्लेषण। कर्नेल OOM किलर द्वारा कंटेनरों को समाप्त करने से पहले चेतावनी वेबहुक सूचनाएं जारी की जाती हैं।
- **स्वायत्त स्व-उपचार (Self-Healing) कंटेनर इंजन**: आउट-ऑफ-मेमोरी क्रैश (`exit 137`) और अस्वस्थ फ़्लैपिंग स्थितियों पर कंटेनर रिकवरी को ट्रिगर करने वाले स्वचालित उपचार नियम, जो घातीय बैकऑफ़ जिटर, सर्किट-ब्रेकिंग संगरोध सीमा और वास्तविक समय प्रोमेथियस टेलीमेट्री द्वारा सुरक्षित हैं।
- **Docker Compose टोपोलॉजी और स्टैक विज़ुअलाइज़र**: `com.docker.compose.project` लेबल द्वारा कंटेनरों का स्वचालित समूहीकरण, इंटरैक्टिव SVG निर्भरता ग्राफ़, वास्तुशिल्प सेवा स्तर पहचान (डेटाबेस, कैश, कतार, गेटवे, कार्यकर्ता) और पूरे स्टैक पर जीवनचक्र नियंत्रण (रीस्टार्ट, स्टॉप, रीक्रिएट)।
- **इन-ब्राउज़र इंटरएक्टिव कंटेनर टर्मिनल (Exec)**: WebSocket (`/api/docker/exec`) पर पूर्ण डुप्लेक्स इंटरैक्टिव शेल टर्मिनल, जिसमें 256 रंगों के साथ उच्च-निष्ठा VT100 / ANSI एस्केप अनुक्रम रेंडरिंग, केवल-पढ़ने की नीति प्रवर्तन और निष्क्रिय सत्र स्वतः-समाप्ति शामिल है।
- **मल्टी-होस्ट एजेंट मेश और रिमोट नोड एग्रीगेटर**: वितरित सर्वरों पर वास्तविक समय क्रॉस-होस्ट कंटेनर निगरानी। डायनामिक नोड पंजीकरण, पीयर स्वास्थ्य जांच, RTT विलंबता ट्रैकिंग, और एकीकृत बहु-नोड कंटेनर टेलीमेट्री।
- **Prometheus मानक मेट्रिक्स निर्यातक**: Grafana में डेटा अंतर्ग्रहण के लिए मानक प्रारूप में होस्ट, कंटेनर, मेश नोड्स, अलर्ट और ऑडिट टेलीमेट्री निर्यात करने वाला मूल `/metrics` एंडपॉइंट।
- **बैच कंटेनर संचालन**: एक-क्लिक और एपीआई-संचालित सिंक्रनाइज़ जीवनचक्र संचालन (`restart_all`, `stop_all`) और स्वचालित निष्क्रिय कंटेनर निष्कासन (`prune`)।
- **थ्रेड-सुरक्षित ऑडिट ट्रेल लॉगिंग**: निश्चित क्षमता वाला सर्कुलर बफर जो 2,000 सुरक्षा और प्रशासनिक कार्यों को रिकॉर्ड करता है, जिसमें स्ट्रीमिंग NDJSON और JSON निर्यात (`/api/audit/export`) शामिल है।
- **स्वचालित TLS परिवहन सुरक्षा**: इन-मेमोरी TLS प्रमाणपत्र इंजन लोकलहोस्ट, लूपबैक और नेटवर्क इंटरफेस के लिए आधुनिक सिफर सुइट्स के साथ ECDSA P-256 स्व-हस्ताक्षरित प्रमाणपत्र और SAN स्वतः उत्पन्न करता है। कस्टम प्रमाणपत्र पूरी तरह समर्थित हैं।
- **Bearer टोकन प्रमाणीकरण और RBAC**: `admin` (पूर्ण नियंत्रण, अलर्ट नियम, लॉग फ़ीड) और `viewer` (केवल-पढ़ने के लिए टेलीमेट्री) के बीच अंतर करने वाला बारीक भूमिका-आधारित अभिगम नियंत्रण, समय पक्ष-चैनल हमलों के खिलाफ निरंतर-समय टोकन तुलना (`subtle.ConstantTimeCompare`) के साथ।
- **स्वचालित वेबहुक अलर्ट**: अप्रत्याशित कंटेनर निकास, क्रैश, या रीस्टार्ट लूप पर Discord (रंग-कोडित एम्बेड) और Slack को त्वरित आउटगोइंग वेबहुक सूचनाएं।
- **विफलता आवृत्ति और फ़्लैपिंग पहचान (Flapping Detection)**: सर्वर आउटेज होने से पहले फ़्लैपिंग और क्रैश-लूपिंग सेवाओं का पता लगाने के लिए स्लाइडिंग विंडो निगरानी।
- **होस्ट संसाधन सीमा निगरानी**: स्वचालित अलर्ट डिडुप्लिकेश़न और कूलडाउन नियंत्रण के साथ कॉन्फ़िगर करने योग्य CPU और मेमोरी उपयोग सीमाएँ।
- **रीयल-टाइम कंटेनर लॉग स्ट्रीमिंग**: शुद्ध मानक-पुस्तकालय RFC 6455 WebSocket स्ट्रीमिंग (`/api/docker/logs`), डॉकर मल्टीप्लेक्स stdout/stderr डेमक्सिंग और REST JSON स्नैपशॉट फ़ॉलबैक के साथ।
- **Docker सॉकेट निरीक्षण और जीवनचक्र नियंत्रण**: सक्रिय कंटेनरों का निरीक्षण करता है और पुष्टि संवादों के साथ एक-क्लिक सुरक्षित कंटेनर रीस्टार्ट, स्टॉप और बैच क्रियाएं प्रदान करता है।
- **होस्ट सिस्टम टेलीमेट्री**: वास्तविक समय CPU कोर, गोरूटीन, आवंटित रैम, GC चक्र और अपटाइम को ट्रैक करता है।
- **मल्टी-प्लेटफ़ॉर्म बाइनरी मैट्रिक्स**: Linux (amd64, arm64), macOS (amd64, arm64 Apple Silicon), और Windows (amd64) के लिए संकलित और सत्यापित।

## 🚀 त्वरित शुरुआत (Quick Start)

### 1. डाउनलोड और चलाएं (स्टैंडअलोन बाइनरी)

```bash
# रिपॉजिटरी क्लोन करें
git clone https://github.com/kLauncher1/dock-radar.git
cd dock-radar

# Go का उपयोग करके सीधे चलाएँ (डिफ़ॉल्ट HTTP पोर्ट 9080)
go run .
```

एंबेडेड वेब कंसोल ब्राउज़र में तुरंत उपलब्ध होगा:
👉 **`http://localhost:9080`**

### 2. TLS और प्रमाणीकरण के साथ चलाएं (उत्पादन सुरक्षित मोड)

```bash
# स्वचालित स्व-हस्ताक्षरित TLS सक्षम करें और एडमिन टोकन सेट करें
go run . --tls --admin-token="my-super-secret-admin-token" --viewer-token="my-readonly-token"
```

सुरक्षित वेब कंसोल यहाँ उपलब्ध होगा:
👉 **`https://localhost:9080`**

### 3. एकल बाइनरी का निर्माण करें

```bash
# डीबग प्रतीकों से मुक्त एक छोटा, स्वतंत्र निष्पादन योग्य फ़ाइल संकलित करता है
go build -ldflags="-s -w" -o dock-radar .

# बाइनरी विकल्प देखें
./dock-radar --help
```

### सुरक्षा गारंटी (Security Guarantees)
- **परिवहन एन्क्रिप्शन (TLS)**: सभी होस्ट इंटरफेस के लिए SAN सत्यापन के साथ इन-मेमोरी ECDSA P-256 स्व-हस्ताक्षरित प्रमाणपत्र जनरेशन या कस्टम प्रमाणपत्र बंडलों का समर्थन करता है।
- **निरंतर-समय प्रमाणीकरण**: टोकन सत्यापन `crypto/subtle.ConstantTimeCompare` पर निर्भर करता है, जिससे साइड-चैनल हमलों का जोखिम समाप्त हो जाता है।
- **बारीक RBAC पृथक्करण**: रीड एंडपॉइंट्स (सिस्टम मेट्रिक्स, कंटेनर सूची, लॉग स्ट्रीम) `viewer` और `admin` दोनों के लिए सुलभ हैं, जबकि उत्परिवर्तन कार्यों के लिए सख्ती से `admin` की आवश्यकता होती है।
- **डिफ़ॉल्ट लूपबैक नीति**: जब कोई प्रमाणीकरण टोकन सेट नहीं होता है, तो स्थिति बदलने वाले एंडपॉइंट स्थानीय लूपबैक इंटरफेस (`127.0.0.1`, `::1`, `localhost`) तक सीमित होते हैं।
- **CSRF और DNS रीबाइंडिंग से सुरक्षा**: क्रॉस-ओरिजिन हमलों को रोकने के लिए आधुनिक ब्राउज़र मेटाडेटा (`Sec-Fetch-Site`) और `Origin`/`Referer` हेडर का सत्यापन किया जाता है।
- **SSRF और क्लाउड मेटाडेटा सुरक्षा**: वेबहुक गंतव्य सख्त HTTP/HTTPS योजनाओं को लागू करते हैं, CRLF वर्णों को फ़िल्टर करते हैं, और क्लाउड इंस्टेंस मेटाडेटा एंडपॉइंट्स (`169.254.169.254`, `metadata.google.internal`) को अस्वीकार करते हैं।
- **पैरामीटर सीमा स्वच्छता**: सभी कंटेनर आईडी और नाम सख्त अल्फ़ान्यूमेरिक पैटर्न (`^[a-zA-Z0-9][a-zA-Z0-9_.-]{0,127}$`) के विरुद्ध मान्य होते हैं।
- **दर-सीमित सुरक्षा**: टोकन बकेट दर सीमक 1 टोकन/सेकंड रिफिल दर के साथ कंटेनर नियंत्रण और अलर्ट एपीआई कॉल को 5 ऑपरेशनों तक सीमित करता है।
