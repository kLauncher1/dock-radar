# 📡 Dock-Radar

**Ультралегкий монитор контейнеров и системных метрик в одном бинарнике со встроенным темным веб-дашбордом.**

<sub>Разработано kLauncher1 · Минимальное потребление ресурсов для домашних серверов и edge-узлов.</sub>

</div>

---

## ⚡ Ключевые Возможности

- **Развертывание в Одном Бинарнике**: Веб-интерфейс встроен прямо в исполняемый файл Go с помощью `//go:embed`. Node.js и внешние веб-серверы не требуются.
- **Ультранизкое Потребление Памяти**: Постоянно работает в пределах **15 МБ ОЗУ**, что идеально подходит для недорогих VPS и Raspberry Pi.
- **Прямое Подключение к Docker**: Взаимодействие через `/var/run/docker.sock` или Named Pipes в Windows с надежным автономным режимом.
- **Телеметрия Хост-Системы**: Мониторинг ядер CPU, горутин, выделенной оперативной памяти, циклов сборщика мусора и времени работы.
- **Темный Glassmorphism Интерфейс**: Четкий информативный дашборд с мониторингом контейнеров, статусами и журналом событий.

## 🚀 Быстрый Старт

```bash
git clone https://github.com/kLauncher1/dock-radar.git
cd dock-radar

# Прямой запуск
go run .

# Сборка автономного бинарника
go build -ldflags="-s -w" -o dock-radar .
./dock-radar
```

Веб-панель: 👉 **`http://localhost:9080`**
